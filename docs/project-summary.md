# Project Summary

**Food Nutrition Calculator** is a premium, professional, US-focused web application that allows users to deterministically calculate calories, macros, and nutrients for foods, recipes, and meals. 

It uses an architecture heavily grounded in accurate data, prioritizing the **USDA FoodData Central API** as the primary source of truth, with a local fallback dataset for offline capability. An AI parser layer is implemented strictly for interpreting user input (natural language parsing) and never for generating actual nutrition facts.

The product positions itself as a robust, luxurious utility without making any false medical claims or guaranteed health outcomes, strictly offering informational value with high performance and accessibility.
